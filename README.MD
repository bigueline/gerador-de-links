# 🔗 Gerador de Links

Meu primeiro projeto desenvolvido durante meus estudos de desenvolvimento web na Rocketseat.

O projeto consiste em uma página de links pessoais, permitindo acesso rápido às minhas principais redes e páginas.

## 🚀 Tecnologias

Este projeto foi desenvolvido utilizando:

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Figma

## ⚙️ Funcionalidades

- Alternância entre modo claro e escuro
- Links para redes sociais
- Links para projetos e portfólio
- Interface responsiva
- Efeitos de hover e transições

## 💻 Projeto

Durante o desenvolvimento deste projeto, pratiquei conceitos como:

- Estruturação de páginas com HTML
- Estilização com CSS
- Flexbox
- Efeitos de hover e transições
- Manipulação de classes com JavaScript
- Modo claro e escuro
- Git e versionamento de código

## 🎯 Aprendizados

Este projeto fez parte dos meus estudos iniciais em desenvolvimento web.

Durante o desenvolvimento, consegui praticar a identificação e correção de bugs, além de compreender melhor a integração entre HTML, CSS e JavaScript.
